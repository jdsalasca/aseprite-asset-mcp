# biomes and maps

Map starters for beaches, oceans, villages and hostile biomes.

Esta carpeta contiene 20 assets deterministas. Cada subcarpeta documenta sus previews, sprite sheets PNG/SVG, GIF animado, manifest y variantes.

## Ejemplos

- [forest](./forest/README.md): forest map starter with layers, landmarks and atmosphere variants.
- [desert](./desert/README.md): desert map starter with layers, landmarks and atmosphere variants.
- [tundra](./tundra/README.md): tundra map starter with layers, landmarks and atmosphere variants.
- [swamp](./swamp/README.md): swamp map starter with layers, landmarks and atmosphere variants.
- [volcanic](./volcanic/README.md): volcanic map starter with layers, landmarks and atmosphere variants.
- [coast](./coast/README.md): coast map starter with layers, landmarks and atmosphere variants.
- [beach](./beach/README.md): beach map starter with layers, landmarks and atmosphere variants.
- [ocean](./ocean/README.md): ocean map starter with layers, landmarks and atmosphere variants.
- [coral reef](./coral-reef/README.md): coral reef map starter with layers, landmarks and atmosphere variants.
- [mountain](./mountain/README.md): mountain map starter with layers, landmarks and atmosphere variants.
- [canyon](./canyon/README.md): canyon map starter with layers, landmarks and atmosphere variants.
- [river](./river/README.md): river map starter with layers, landmarks and atmosphere variants.

## Uso

Busca por categoría con `get_asset_library`, resuelve un item con `get_asset_library_item` y aplica las variantes con los algoritmos del MCP sobre una copia del asset.

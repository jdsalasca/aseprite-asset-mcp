# mounts

Mounts with travel and movement states.

Esta carpeta contiene 12 assets deterministas. Cada subcarpeta documenta sus previews, sprite sheets, manifest y variantes.

- [warhorse](./warhorse/README.md): warhorse mount with travel poses.

- [elephant](./elephant/README.md): elephant mount with travel poses.
- [dire wolf](./dire-wolf/README.md): dire wolf mount with travel poses.
- [griffin mount](./griffin-mount/README.md): griffin mount mount with travel poses.

## Uso

Busca por categoría con `get_asset_library`, resuelve un item con `get_asset_library_item` y aplica las variantes con los algoritmos del MCP sobre una copia del asset.
